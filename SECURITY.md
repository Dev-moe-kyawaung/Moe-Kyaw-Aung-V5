# Security Policy

## Supported versions

This project is maintained on the `main` branch only. Security fixes will be applied to the latest active version of the repository.

## Reporting a vulnerability

If you discover a security issue, please do not open a public issue.

Instead, report it privately by emailing:

**security@yourdomain.com**

If you do not have a dedicated security email yet, use the repository owner’s private contact method or GitHub’s private vulnerability reporting feature if enabled.

## What to include

Please include:

- A short description of the issue.
- The affected files or feature.
- Steps to reproduce.
- Any proof of concept, if available.
- Your preferred contact details.

## What happens next

- We will acknowledge receipt as soon as possible.
- We will investigate and validate the report.
- We will coordinate a fix before public disclosure when appropriate.

## Scope

This policy applies to:

- Source code in this repository.
- GitHub Actions workflows.
- Hosting configuration files.
- Deployment secrets or configuration that could expose the application or users.

## Safe disclosure

Please give the maintainers reasonable time to investigate and patch the issue before publishing details publicly.
